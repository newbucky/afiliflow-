# 🚀 AfiliFlow — Automação de Ofertas para Telegram
 Sistema que busca produtos em promoção na Shopee, converte para link de afiliado e posta automaticamente nos grupos do Telegram.
 ## ⚙️ Configuração
 Todas as configurações ficam nas Variáveis de Ambiente do Netlify.
 ## 📖 Comandos do Bot
 - /start — Bem-vindo e lista de comandos
 - /adicionargrupo — Adiciona o grupo para receber ofertas
 - /listagrupos — Ver grupos cadastrados
 - /removergrupo — Remove o grupo atual
 - /status — Ver status do sistema
 - adicionar [link] [desconto] — Adiciona oferta manual (Mercado Livre)
